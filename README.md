# Restaurant Booking

A restaurant table booking application built with Next.js and React.

## Tech Stack

- **Next.js 16.1.6** - React framework with Pages Router
- **React 19.2.4** - UI library
- **TypeScript 5.9.3** - Type safety
- **Formik & Yup** - Form management and validation
- **SCSS** - Styling with CSS Modules
- **Biome** - Linting and formatting

## Getting Started

Install dependencies:

```sh
npm install
```

Run the development server:

```sh
npm run dev
```

Application will run on [http://localhost:3000/](http://localhost:3000/)

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build production bundle
- `npm start` - Build and start production server
- `npm run lint` - Run Biome linter
- `npm run format` - Format code with Biome
- `npm run check` - Run linter and formatter with auto-fix

## Features

- Restaurant table booking form with validation
- Guest count selector with visual table representation
- Form state management with Formik
- Responsive design
- Animated UI elements
